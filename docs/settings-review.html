🗑️ Cut : 79 settings removed from the UI

Six more were cut after an audit found they had a control but no effect: Hand Strength Hints, Win Probability, Confirm All-in, Confetti on Win, Table Theme and Color Blind Mode. Nothing in the app ever read them, so the toggle moved and the game did not. Card Back, Show Names, Large Text and Ante were in the same state and were implemented instead of cut.
